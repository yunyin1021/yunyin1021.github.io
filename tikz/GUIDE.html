打开方式

解压整个压缩包，双击最外层的 index.html，或进入 dist 双击 index.html。保留同目录结构，不能只取一个 HTML 文件。

Mac 与 Windows 使用同一个包。使用者只需现代浏览器，不需要安装 Python、TeX、Node，也不需要命令行。建议桌面 Chrome / Edge / Safari。工程、数学排版及图片生成均在浏览器完成。公式组件 MathJax 已放在包内，不调用在线编译服务或公共 CDN。

如果某个浏览器限制从本地文件加载脚本、剪贴板或存储，请使用已经部署到个人主页的 HTTPS 版本。网站访问者仍只需浏览器。此原型未添加离线安装或 Service Worker；关闭在线页面后，不保证再次打开网址可离线使用。下载完整包后可本地打开。

快速操作

线段和矩形 / 椭圆按下拖动创建。折线 / 多边形 / 钢笔曲线逐点点击，按 Enter 或双击结束；曲线建立后拖动控制柄调整。右键锚点选择平滑或尖点。普通线在属性中可从起点或终点再加一段，交换图箭头没有此选项。

空白处拖动框选；Shift / Alt / Command / Ctrl 可追加选择。右键执行组合；组合不嵌套，新组合会先解除涉及的旧组合。双击组合成员可进入组内单选，点空白退出。所选图形上方圆点用于旋转，中间圆点可移动旋转中心；Shift 旋转按 15° 对齐。

鼠标滚轮围绕光标缩放；触控板平行滑动平移，捏合缩放。不同设备的滚动事件不同，可用下方按钮 / 滑条 / 手形浏览替代。浏览模式锁定对象拖动，仍可右键。画布以 cm 为单位，原点左下，y 向上；屏幕向下的 y 在显示层取负号。

内容框默认普通文字，支持中文。数学部分自己写 $x^2$，也可混排 集合 $A$。不要给普通文字强加 $。不支持标签内复杂段落换行。

默认 Command / Ctrl + Z 撤销、Shift + Command / Ctrl + Z 或 Ctrl + Y 重做、C / X / V 复制剪切粘贴、S 下载工程、O 打开、A 全选。新建使用 Command / Ctrl + Alt + N，以减少与浏览器新建窗口冲突。数字 0 适应画布，空格切换浏览。输入框内优先使用系统文字编辑快捷键。浏览器或系统保留按键无法保证覆盖。

保存和导出格式

格式作用可继续编辑
.json完整工程，含分组、控制柄、箭头参数、画布和 TeX 导言是，首选保存方式
可再编辑 .textikzpicture 加结构元数据注释原样导回此版可完整恢复
纯 .tex简短 TikZ 图片环境，含对象编号注释，适合放入自己的论文只可反向识别下述有限语法
完整 .tex 示例带文档头和必要宏包，可交给自己的 XeLaTeX 编译用 JSON 保留结构
.svg矢量图，公式为路径，普通文字用系统字体不支持 SVG 导入
.png位图，保留透明背景否
.jpg位图，没有透明；背景颜色可选否

图片导出裁切至画布，不带方格、参考线和选择柄。PNG / JPG 可设宽度，最多 6000 像素宽且总像素不超过 3200 万。TikZ 保留全部图形，包括画布外对象，画布背景颜色目前仅体现在图片导出及 JSON 中；需要在论文里设置底色时自行增加背景。此版不提供 PDF 编译输出。

下载通常进入浏览器的“下载”目录；浏览器可能直接下载而不弹出路径窗口。Finder 可在设置中开启显示文件扩展名。不要将未应用的源码草稿误认为已更新的图形。

代码编辑的真实范围

“生成 TikZ”与“能解析任意 TikZ”是两件不同的工作。此版本不承诺任意 TikZ 的双向可视化。

1. 从 JSON 打开，完整恢复本版支持的对象、参数、分组。兼容桌面版 v0.4.1 的 version=4 结构化工程；也迁移 version=3 数学标签。处于任意外部 TeX 预览模式的工程不能在纯前端执行。

2. “可再编辑 TikZ”包含 % TIKZ-STUDIO-WEB ... 的数据注释。原样导入恢复完整结构。若改动正文，将尝试有限解析，不能依靠注释忽略改动。

3. 当前工程代码区可改本版 node / text 的 at (x,y)、文字、rotate。这些修改会更新节点及与它连接的箭头。支持删除完整对象块，但不能留下悬空箭头。

4. 修改曲线控制点、绘图命令、复杂样式、任意新增命令，通常不能反向解析。请在可视化属性中调整，或使用 AI 提示词转成 JSON。

5. 超出解析范围时，保留源码草稿，画布停留在上一次成功状态；点击“应用代码”可查看原因。可复制 / 下载草稿；“恢复生成代码”会询问后丢弃草稿。草稿也单独本地保存。

6. 独立导入“纯代码”不保证完整恢复本版的所有复杂图形；欲在新浏览器完整继续编辑，请用 JSON 或“可再编辑 TikZ”。

可识别的外部 TikZ 极简示例（只支持命名绝对坐标节点和直线，above / below 标签）：

\begin{tikzpicture}
\node (A) at (2,5) {$A$};
\node (B) at (7,5) {$B$};
\draw[->] (A) -- node[above] {$f$} (B);
\end{tikzpicture}

不支持直接执行 tikz-cd 矩阵、\foreach、相对定位、任意 \tikzset、宏展开、外部图片、任意库及带复杂选项的外部路径。可参考随包的 AI_TRANSCRIPTION_PROMPT.md 转录，AI 结果仍需自己校对。

TeX 导言那几行的用途

设置中的导言只用于下载“完整 TeX 示例”，不在网页中执行：

\usepackage{tikz,amsmath,amssymb}
\usepackage[UTF8,fontset=fandol]{ctex}
\usetikzlibrary{patterns}

第一行引入绘图、常见数学排版和数学符号；第二行提供中文排版及 Fandol 字体，建议使用 XeLaTeX；第三行启用图案填充。纯代码复制只含 tikzpicture，粘到自己的 TeX 文档时需在导言区引入必要宏包。你可添加导言，但不会让网页因此获得相应 TeX 库能力。

与桌面版的限制和缺失

  • 没有 TeX 编译后端，也不调用他人的编译服务器。数学排版使用 MathJax 的 TeX 数学子集，与 XeLaTeX 的字体、间距及完整编译结果不能保证高度一致。
  • 不执行任意 TeX / TikZ 库、导言宏及复杂外部源码；不能让任意 TeX 源码直接变成可拖动图形。代码双向编辑范围见上节。
  • 未提供：真正 TeX PDF、自动 AI 转录、自定义箭头预设编辑器、交换图同节点自环、SVG 导入、嵌套组合、云端同步、多人协作。视觉自环可用钢笔绘制。
  • 单射 / 满射 / 同构是箭头标记预设，形式对偶变换只改变图形，不验证范畴论命题。没有自动验证图形是否交换。
  • 每工程最多 500 对象；多条长曲线的交点判断会变慢。曲线交点及装饰使用采样近似，不是符号几何求解。
  • 主要界面和导出选项有中英文，部分解析 / 异常诊断仍为中文。移动端提供上下布局，但精细曲线编辑以桌面鼠标操作为主。
  • 剪贴板、触控手势、下载位置及保留快捷键受浏览器影响。若系统剪贴板不可用，画布右键复制粘贴使用应用内剪贴板；代码可手动选中复制。
  • 普通文字依赖本机字体，不嵌入 SVG 字体；不同电脑可能排版稍有差异。公式 SVG 路径随导出携带。
  • 网页存在常规浏览器缓存和本地存储，不能承诺删除网页文件夹即从电脑完全不留痕。设置中可清除该编辑器的自动保存和偏好；网络缓存需在浏览器设置清理。清理后继续编辑会重新自动保存。

部署到个人主页 / GitHub Pages

无需租额外编译服务器。这里只需要能提供 HTML / CSS / JS 的静态托管。

已有个人主页：把 dist 里的所有内容 放进主页发布目录下的 tikz/（保留 vendor 整个目录），然后在主页添加链接：

<a href="./tikz/">TikZ 绘图编辑器</a>

也可放进页面：

<iframe src="./tikz/" title="TikZ 绘图编辑器"
        style="width:100%;height:900px;border:0"
        allow="clipboard-read; clipboard-write"></iframe>

独立页面的可用空间和快捷键体验更好。跨站 iframe 的剪贴板和存储可能受额外限制；应用内复制粘贴仍可使用。

新建纯静态 GitHub Pages 仓库时，把 dist 内文件放在发布来源根目录，入口是 index.html；在仓库 Settings → Pages 配置发布来源。.nojekyll 已随包提供。如果原主页用 Jekyll / Hugo / 其他构建方式，将文件放在该工具会原样复制的静态目录中；不要改动原主页的构建配置。

更新时覆盖相应静态文件并发布，访客刷新后加载新版。若改了 JS / CSS，应同时更新 index.html 中的 ?v= 版本号。无需访客安装或更新桌面软件。托管仍可能有维护、故障和服务限制，不代表绝对不会被攻击；应用没有登录或后端，并不等于整个托管账号没有风险。

官方部署说明：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

本地存储和隐私

代码没有远程上传、账号、统计或在线 AI 调用。只使用两个同站点 localStorage 键保存本编辑器的数据：yunyi.tikzstudio.web.v1 和 yunyi.tikzstudio.preferences.v1。网页托管方仍可能记录常规访问日志。

清理按钮只删除这两个键，不清理个人主页其他应用的数据。浏览器页面关闭后不会继续运行；没有安装后台服务。下载的 JSON / TeX / 图片属于用户主动保存文件，清理按钮不会删除。无痕模式、本地文件模式、浏览器清理或存储配额可能影响自动保存，重要作品务必下载 JSON。
